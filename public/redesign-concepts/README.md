# TezHR marketing redesign concepts

Art direction: **THE CUT**.

TezHR cuts a clean path through résumé noise. The slash is the identity, layout device, motion path, and recurring proof mechanism across the marketing site.

The seven concept images in this folder cover:

1. Homepage — résumé pile to shortlist
2. Product evidence — explainable score and human decision
3. Sourcing — one route across local hiring sources
4. Local intelligence — three languages, one fair score
5. Trust — visible chain of custody for candidate data
6. About — built close to the problem in Tashkent
7. Contact — one direct line to the builder

These are visual direction images only. No production UI or backend behavior is implemented here.
